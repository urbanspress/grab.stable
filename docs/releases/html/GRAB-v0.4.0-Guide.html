Core Standard Library, Error Model & Permissions

The Safe Vault: Professional Utilities, Crash Recovery & Default-Deny Security

GRAB 0.4 introduces built-in standard modules for text, math, collections, dates, and files, alongside a crash-proof `try`/`catch` error handling model and default-deny security capabilities.

💡 Everyday Metaphor: The Keycard Security Vault

In a secure shopping mall, employees can only enter stockrooms with an authorized electronic keycard. They cannot wander into confidential offices. GRAB 0.4 enforces default-deny security: a program cannot read or write any file on the server unless the server administrator explicitly grants permission (`--allow-read`). If an unexpected error happens—like an expired coupon—the clerk catches it cleanly (`try`/`catch`) instead of dropping everything.

⚙ Backend: What Grisp & GRAB Do
5 Built-In Standard Modules

`use text`, `use math`, `use collections`, `use dates`, and `use files` ready out of the box.

Structured `try` / `catch`

Errors are rich record values containing code, message, and line numbers; unhandled crashes are eliminated.

Default-Deny File Permissions

Access to files fails closed unless granted via `--allow-read` / `--allow-write`; blocks `.env` / `/etc/`.

Three Diagnostic Modes

`beginner` (friendly guidance), `developer` (detailed spans), and `production` (redacted, hardened logs).

4 Real-World Code in Action
Crash-Proof Promo Code Handler with Formatting
use text
use files

make apply_promo using code, subtotal
  try
    if code is not "HOLIDAY20"
      raise record {code: "INVALID_PROMO", message: "Promo code not found"}
    end
    set discount to subtotal times 0.20
    give back record {valid: yes, discount: discount, message: "20% off applied!"}
  catch err
    give back record {valid: no, discount: 0.00, message: err.message}
  end
end
