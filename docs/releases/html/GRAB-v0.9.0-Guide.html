⚙ Backend: What Grisp & GRAB Do
Two-Tier Execution (`--engine=auto`)

Cold scripts run on AST; hot functions (16 calls), loops (64 back-edges), and routes (8 hits) promote dynamically to VM bytecode.

Pre-Indexed Lexical IR

Lowers AST nodes into compact intermediate representations with pre-allocated local stack slots (`OpGetLocal`).

Fail-Closed Static Verifier

Validates stack bounds, instruction types, constant pools, and jump targets before any bytecode chunk executes.

Structured PC-Range Tables

Zero-allocation happy-path error handling; exception handlers are resolved via binary search only when an error is raised.
