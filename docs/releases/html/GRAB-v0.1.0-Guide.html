Core Language Foundation & Exact Arithmetic

The Honest Cash Register: Why Precision Math Matters for Modern Commerce

GRAB 0.1 establishes a pure Go-implemented, deterministic programming foundation where calculations never introduce floating-point drift, ensuring every financial calculation is mathematically exact.

💡 Everyday Metaphor: The Honest Mechanical Register

Imagine a traditional metal cash register with precisely machined gears. When you ring up a $19.95 shirt, the mechanical wheels lock into exact cent positions. In contrast, standard programming languages (like Python or JavaScript) use binary floating-point math that introduces tiny fractional ghosts, turning $19.95 into $19.949999999999999. GRAB 0.1 is engineered from day one to guarantee that money never rounds wrong.

⚙ Backend: What Grisp & GRAB Do
Exact Decimal Representation

Built on arbitrary-precision integers and fixed-point decimals (`grabrt.DecimalKind`), separating money from floating-point approximations.

Deterministic Text Output

Standardized LF line endings and UTF-8 encoding across Windows, macOS, and Linux servers.

Strict Value Isolation

Values are portable, immutable representations: Text, Boolean (yes/no), Nothing, Integer, Decimal, Float, Bytes, Lists, and Records.

Clear Compiler Errors

Locates exact line and column numbers (GRAB-E001 to GRAB-E103) so errors can be diagnosed in seconds.
