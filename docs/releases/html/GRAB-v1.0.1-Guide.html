CLI Version Reporting Polish & Release Packaging

Instant Build Verification: Clean 4-Line Version Banner & Reproducible Release Binaries

GRAB 1.0.1 refines the developer and operator CLI experience with instant version, build timestamp, platform architecture, and runtime identification via `grab -v`, `grab --version`, and `grab version`.

💡 Everyday Metaphor: The Stamped Brass Nameplate

Every commercial espresso machine or storefront oven carries a stamped brass nameplate showing its exact model, build date, and certification. GRAB 1.0.1 adds that same unmistakable nameplate to the `grab` CLI—so whether you are checking a local laptop install or a production Linux container, one quick command confirms the exact version and build timestamp.

How this milestone elevates what the online shopper sees on their screen and what the GRAB platform guarantees behind the scenes.

👁 Frontend: What the Shopper Sees
Zero-Guesswork Support

Store owners and operators can run `grab -v` to report exact runtime details when troubleshooting or upgrading.

Consistent CLI Ergonomics

Supports `-v`, `--version`, and `version` subcommand conventions familiar to PHP, Go, and Node developers.

Clean Exit Behavior

Returns exit code `0` cleanly for automated health scripts, CI pipelines, and desktop installer checks.

Production Branding

Clearly identifies the Urbanspress copyright and Grisp Persistent Application Server & Native MCP Runtime.

⚙ Backend: What Grisp & GRAB Do
Build-Time `-ldflags` Injection

Supports `-X main.Version=...` and `-X main.BuildDate=...` (`MMM DD YYYY HH:MM:SS`) with safe `1.0.1` / `unknown` defaults.

Runtime Target Reporting

Automatically prints `GOOS`, `GOARCH`, and the exact Go toolchain version (`go1.27.3`).

Automated CLI Unit Tests

Verified by `TestVersion_CLI` in `cmd/grab/main_test.go` covering defaults, custom `-ldflags`, and invalid extra args.

100% Full Suite Verification

All 19 testable Go packages verified passing via `go test -count=1 ./...` prior to `v1.0.1` release.
