Persistent Application Server (Grisp Engine)

The 24/7 Superstore: Zero-Cold-Start Speed, High Concurrency & Live Reloads

GRAB 0.6 transforms GRAB into a high-performance persistent web server (Grisp Engine), loading code and templates once into memory for sub-millisecond route handling and zero-downtime reloads.

💡 Everyday Metaphor: The Permanent Flagship Store

Running scripts via command-line execution is like setting up a temporary folding table for every customer, taking it down, and packing up when they leave. GRAB 0.6 opens a permanent, 24/7 flagship superstore. The lights are on, registers are warm, and staff are standing by. When thousands of shoppers enter simultaneously, they are served in parallel with zero startup lag. When changing store displays, new inventory loads in the background with zero disruption.

1 The Customer Browsing & Buying Experience Walkthrough

How this milestone elevates what the online shopper sees on their screen and what the GRAB platform guarantees behind the scenes.

👁 Frontend: What the Shopper Sees
Sub-Millisecond Page Loads

Product pages, search queries, and category catalogs render in 2 to 5 milliseconds with zero cold starts.

Zero 502 Downtime Deploys

Store updates and layout refreshes happen atomically in the background; shoppers never see broken pages.

Instant Static Asset Delivery

CSS stylesheets, store logos, and client JavaScript serve with HTTP ETags and 304 Not Modified caching.

Graceful Traffic Handling

During traffic spikes, requests queue orderly without dropping shopping carts or crashing the server.

⚙ Backend: What Grisp & GRAB Do
Load-Once `PreparedApp`

Parses and compiles all `.grab` routes and `.grab.html` templates once at boot into immutable memory structures.

Bounded Concurrency & Queues

Controls max concurrency (default 64) and queue depth (default 128) with deadline timeouts to prevent memory exhaustion.

Atomic Last-Known-Good Reload

Tests new code in an isolated generation before swapping active pointers; rolls back safely if syntax errors exist.

Confined Static Serving

Serves static directories (`--static`) with strict path confinement, blocking directory traversal attacks.
