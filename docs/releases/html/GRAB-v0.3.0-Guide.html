GRAB 0.3 turns GRAB into a complete, structured general-purpose language with conditionals, bounded loops, isolated function calls, and safety limits preventing server lockups.

💡 Everyday Metaphor: The Manager's Rulebook

Imagine a store manager with an exact set of operating rules: 'If the customer is a VIP, give 10% off. For each item in their basket, check stock. If subtotal exceeds $50, wave shipping.' But unlike human workers who might get confused or trapped in an endless circle, GRAB includes a built-in safety guard: if any calculation repeats more than 1,000,000 times, it halts immediately, protecting the storefront from crashing.

⚙ Backend: What Grisp & GRAB Do
Structured Conditionals

`if` / `otherwise if` / `otherwise` with compile-time exhaustive binding validation.

Bounded Safe Loops

`repeat`, `for each`, and `while` loops guarded by a hard 1,000,000-step runtime check (GRAB-E307).

Isolated Function Calls

`make` / `using` / `give back` / `call` with strictly isolated memory frames and 256-frame recursion limit.

Unified Collection Lookups

Dot syntax (`order.total`), index lookups (`at 1`), and existence tests (`has 'coupon'`).

4 Real-World Code in Action
VIP Discount & Cart Totals Function in GRAB 0.3
make calculate_order using cart, is_vip
  set subtotal to 0.00
  for each item in cart
    set subtotal to subtotal plus (item.price times item.qty)
  end
  if is_vip is yes and subtotal >= 50.00
    set discount to subtotal times 0.15
  otherwise
    set discount to 0.00
  end
  set final_total to subtotal minus discount
  give back record {subtotal: subtotal, discount: discount, total: final_total}
end
