How grab mcp keeps AI assistants accurate

Instead of letting AI assistants guess GRAB syntax or read sensitive files, grab mcp runs a locked-down local tool server over standard input/output.

1 · CONFINEStarts pinned to a single --workspace folder in read-only mode by default.
2 · INSPECTAI agents list routes and schemas without running code or touching secrets.
3 · VALIDATEgrab_check and grab_format verify syntax, types, and HTML escaping locally.
4 · SCAFFOLDWith --allow-write, grab_scaffold generates verified starter files.

Key pillars in plain English

01 · Native MCP Server (ADR-027a)

grab mcp for AI agents

Exposes five safe tools (grab_check, grab_format, grab_inspect_routes, grab_inspect_schema, grab_scaffold) over JSON-RPC stdio for Groxy AI, OpenCode, Antigravity, and Codex.

Developer: AI assistants stop hallucinating syntax or touching .env / .git.
Visitor: apps built with AI assistance stay strictly validated and secure.

02 · Smart Asset Cache-Busting (ADR-027b)

server.asset + immutable caching

At startup or reload, GRAB hashes static files in memory (working even in --read-only containers) and turns "app.css" into /static/app.css?v=a1b2c3d4e5f6.

Developer: zero build-step asset manifest files to manage.
Visitor: instant repeat page loads with 1-year browser caching and zero stale CSS after deploys.

03 · v1.0.0 Stability Freeze (ADR-027c)

Guaranteed backward compatibility

Freezes GRAB's core grammar, exact decimal/integer math, GRAB-E... error codes, .grab.html escaping, all 14 standard modules, and AST/VM parity across the entire v1.x line.

Developer: programs written for v1.0.0 keep working across v1.x updates.
Visitor: predictable, reliable behavior without surprise breaking upgrades.

04 · Production Release Gates (ADR-017, ADR-027d)

Audited & verified before stable

Requires 100% passing Windows/Linux tests, Linux race checks, govulncheck clean scan, GRAB 0.8 30-minute load evidence, and cross-platform binary checks before promoting to stable.

Developer: clear checklist before tagging v1.0.0.
Visitor: production deployments backed by security and endurance verification.
