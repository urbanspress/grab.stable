GRAB 0.4: Core Standard Library, Error Handling & Security

GRAB 0.4 equips the language with everyday building blocks (text formatting, math rounding, dates, list helpers, and safe file access), polite crash-proof error handling (try / catch), locked-down file permissions, and instant developer tools (grab check and grab format).

In one sentence: GRAB 0.4 gives the coder everyday tools so the website looks polished, handles mistakes gracefully, protects private server files, and never crashes in front of the customer.

Why GRAB 0.4 Matters (In Plain English)

How every upgrade in specifications/GRAB-STDLIB-SPEC-004.md improves life for both the builder and the customer.

Builder What It Does for the Coder

  • No more building basic tools from scratch: Turning a number like 19.95 into text ("$19.95"), rounding currency, updating lists, checking dates, or reading text files takes a single readable call instead of custom workarounds.
  • Programs stay online when inputs go wrong: Instead of shutting down over an invalid visitor number or missing file, try / catch lets the coder handle the problem cleanly and keep going.
  • Built-in tidiness & instant bug checks: grab check verifies code and HTML templates in milliseconds before running the server, and grab format keeps spacing and indentation uniform automatically.
  • Plain-English help when learning: Running with --diagnostics beginner points directly to typos and explains how to fix them with a helpful Hint:.

Visitor What It Does for the Website Visitor

  • Clean, polished pages: Visitors see properly formatted prices ($19.95 or $21.55 after tax), tidy dates, and well-organized product tags instead of raw numbers or awkward computer formatting.
  • No scary blank screens or server crashes: If a visitor types letters into a quantity box or looks up a missing item, they see a calm, polite message explaining what to adjust—never a sudden blank crash screen.
  • Stronger privacy & security: Programs have zero file access by default unless explicitly permitted with --allow-read / --allow-write, and GRAB automatically blocks access to sensitive secrets like .env, .git, .ssh, and private keys.
  • Safe production error display: In production diagnostic mode, internal server paths and source code snippets are never shown to visitors.

Features in Action: Developer Console vs. Website Experience

Examples aligned directly with specifications/GRAB-STDLIB-SPEC-004.md.

1. No More Building from Scratch: Everyday Text, Math & Collection Helpers

use text · use math · use collections

Remember asking how 19.95 gets a $ sign in front of it? With GRAB 0.4, use text provides text.from to turn exact decimals into text so your .grab script can compute tax, round to 2 decimal places, and build clean price labels.

product_pricing.grab — Code Editor
# Declare needed standard library modules at the top use text use math use collections set product to record {sku: "A-17", price: 19.95, tags: ["new", "sale"]} set taxed to math.round using (product.price times 1.08), 2 set price_label to "$" joined with (text.from using taxed) set all_tags to collections.append using product.tags, "featured" set tags_line to text.join using all_tags, ", " show price_label show tags_line
Browser http://127.0.0.1:8080/
SKU: A-17
Canvas Work Bag
$21.55 (includes 8% tax)
new sale featured
CLI output (grab run):
$21.55
new, sale, featured
Developer benefit: Exact half-even rounding (math.round), immutable list appends, and number-to-text formatting in one readable script.
Visitor benefit: Crisp, trustworthy pricing badges like $21.55 with zero floating-point rounding glitches.

2. Crash-Proof Recovery: Structured Errors with try / catch / raise

Error Handling · GRAB-E308 / GRAB-E309

Functions can reject invalid business rules with raise, and calling code wraps risky work in try ... catch err ... end. Fatal resource limits (GRAB-E306 stack overflow and GRAB-E307 execution limit) still terminate immediately so infinite loops can never hang a server.

checkout_discount.grab — Code Editor
use text make apply_discount using price, percent if percent is greater than 50 raise "Discount cannot exceed 50%" end give back price minus (price times percent divided by 100) end try set final_price to apply_discount using 100, 75 set notice to "Discount applied!" catch err # err is a record with .code, .category, .message, .line, .column set notice to err.code joined with ": " joined with err.message set final_price to 100 end show notice show "$" joined with (text.from using final_price)
Browser http://127.0.0.1:8080/
Could not apply promo code:
GRAB-E308: Discount cannot exceed 50%
Fallback Price Kept Safely
$100
Developer benefit: Exhaustive branch tracking verifies final_price and notice are defined in both try and catch paths before running.
Visitor benefit: Mistakes return helpful warnings and safe fallback values instead of breaking checkout.

3. Built-In Security Guardrails: Default-Deny File Permissions

Security · ADR-009 · GRAB-E401

Programs start with zero permission to read or write files on disk. Builders unlock specific folders with --allow-read or --allow-write, while GRAB unconditionally blocks sensitive paths like .env, .git, .ssh, private keys, and .. directory escapes.

Terminal — Capability Enforcement
# 1. Default run (no capability flags passed): PS C:\Development\GRAB> grab run catalog_reader.grab error [GRAB-E401]: permission denied (line 2, column 6) No read capability covers "data/catalog.txt". # 2. Explicitly grant read access only to ./data: PS C:\Development\GRAB> grab run --allow-read=./data catalog_reader.grab Loaded 42 catalog items from ./data/catalog.txt # 3. Sensitive files are ALWAYS blocked even inside allowed folders: PS C:\Development\GRAB> grab run --allow-read=. check_env.grab error [GRAB-E401]: permission denied Access to sensitive path ".env" is unconditionally denied.
Security Policy Summary
Allowed when explicitly granted:
Regular UTF-8 files under ./data/ up to 10 MiB.
Always blocked (GRAB-E401):
.env · .git · .ssh · id_rsa · *.pem · *.key · ../ escapes
Developer benefit: Clear capability flags show at a glance what folders any script is allowed to touch.
Visitor benefit: Even if malicious input tries to trick a file path, private credentials and server keys stay unreachable.

4. Instant Code & Template Checks: grab check & grab format

Developer CLI Tooling

Before deploying or starting grab serve, developers validate scripts and companion .grab.html templates statically—catching typos and cleanly formatting source files.

Terminal — Pre-Flight Check & Formatting
# Check code + HTML template without executing any side effects: PS C:\Development\GRAB> grab check product.grab product.grab.html (exits cleanly with code 0 and zero errors) # Example when an HTML tag references a missing variable: PS C:\Development\GRAB> grab check product.grab broken.grab.html error [GRAB-E201]: unbound variable reference "prodct_title" --> broken.grab.html:12:9 # Normalize spacing & 2-space indentation automatically: PS C:\Development\GRAB> grab format --write product.grab
Why Teams Rely on This Step
1. Catch template mismatches early:
Verifies every {placeholder} in .grab.html matches a bound variable and safe HTML escaping context before users visit.

2. Canonical 2-space formatting:
Preserves # comments while normalizing spacing, blocks, and LF line endings across the project.
Developer benefit: Catches broken references in milliseconds without running database or file tasks.
Visitor benefit: Broken placeholders or half-formatted pages don't make it to the live site.

5. Right Message for Every Audience: Three Diagnostic Modes

--diagnostics beginner | developer | production

The exact same error—for example, misspelling price as prce (GRAB-E201)—adapts cleanly depending on who is viewing it.

1. --diagnostics beginner Learning
error [GRAB-E201]: unbound variable reference "prce" --> app.grab:4:17 4 | set total to prce times 2 | ^^^^ Hint: You tried to use "prce", which has not been defined with "set" yet. Did you mean "price" (set on line 2)?
2. --diagnostics developer (default) Debugging
error [GRAB-E201]: unbound variable reference "prce" --> app.grab:4:17 Includes exact line, column, stable GRAB-E201 code, and function call stack trace when inside a function.
3. --diagnostics production Public Safety
error [GRAB-E201]: unbound variable reference Hides internal file paths, source snippets, and internal variable names so server internals never leak to visitors.
Developer benefit: Beginners get plain-English hints while experienced devs keep fast, concise stack traces.
Visitor benefit: Public production mode hides server paths, code lines, and internal data structures.
