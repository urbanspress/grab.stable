Built on the deterministic GRAB language and hardened server engine, the GRAB Ecosystem unites Griss (our snappy multi-worker server), GrabLab (our savvy CMS), Grex & Grex JS (visual page builder and reactive UI runtime), Groxy AI (local MCP design and CMS agent), and Gashboard + Grabtaculous (our discreet desktop VPS manager and 1-click app marketplace).

Roadmap details live in docs/ROADMAP.md and hosting rules live in Deployment Architecture.

Application Server Runtime Builds on 0.6/0.7 · 0.8 & Post-1.0

Griss — Snappy Multi-Worker Server

The persistent GRAB application server that Nginx or Caddy passes the "rock" to on private loopback ports (127.0.0.1:8765–8772), delivering Swoole/Go-class speed with zero cold starts.

For Non-Coders / Owners: Pages respond instantly instead of booting a heavy script on every visitor click, handling traffic spikes without crashing.
For Designers: Live previews and published sites feel crisp with fast page transitions and clean edge caching.
For Developers: Compiles routes/templates once in RAM (PreparedApp), reuses warm DB/Redis pools, and coordinates zero-downtime reloads via /_ready.
Flagship CMS Planned Ecosystem (Post-1.0)

GrabLab — The Savvy CMS

A modern Content Management System built directly on the stable GRAB 1.0 platform (ADR-010), giving teams full publishing power without WordPress legacy baggage.

For Non-Coders / Owners: Manage posts, pages, media, custom content types, roles, and clean URLs (including automatic 301 redirect history when a slug changes) from one organized place.
For Designers: Clean theme/template hooks and structured content fields mean designs never fight mystery shortcodes.
For Developers: Strict capability boundaries, deterministic GRAB data contracts, extensible plugins, and WordPress-style pretty permalinks (/:slug) out of the box.
Page Builder & Reactive UI Planned Ecosystem (Post-1.0)

Grex & Grex JS — Visual Builder & Engine

A responsive-first visual page builder (Grex) paired with a lightweight reactive frontend engine (Grex JS)—built to outperform Bricks, Elementor, and Divi with zero wrapper-div bloat.

  • Native Responsive-First Elements: Flex/Grid containers, typography, media, forms, nav, tabs/accordions, and dynamic query loops.
  • Global Style & Class Manager: Centralized design tokens and reusable Bricks-style classes with Desktop/Tablet/Mobile breakpoint overrides.
  • Conditional Theme Builder & Dynamic Data Picker: Headers, footers, archives, and 404s bound visually to GrabLab & GRAB data with live preview and rollback.
For Non-Coders, Designers & Developers: Drag-and-drop speed for owners, pixel-accurate classes/breakpoints for designers, and clean semantic HTML + fast Grex JS interactivity for developers.
Autonomous MCP Agent Planned Ecosystem (Post-1.0)

Groxy AI — Autonomous Design & CMS Expert

An autonomous site designer and GrabLab expert agent powered by grab mcp, GRAB-DESIGN-SYSTEM.md, and cost-free local models via Ollama + OpenCode.

For Non-Coders / Owners: Describe a landing page, catalog, or content type in plain English and let Groxy AI build and verify it with zero recurring AI API bills.
For Designers: Follows spacing, typography, and accessibility guardrails in GRAB-DESIGN-SYSTEM.md using native Grex components instead of messy inline CSS hacks.
For Developers: Inspects schemas, scaffolds routes/templates, and checks every generated file through grab mcp and grab check before saving.
Desktop VPS Control Panel Planned Ecosystem (Post-1.0)

Gashboard — Discreet Desktop Control Panel

A discreet desktop-based VPS control panel that eliminates public web-panel login attack surfaces by managing your server remotely over encrypted connections.

For Non-Coders / Owners: Point-and-click VPS management—add custom domains with automatic edge SSL (Caddy or Nginx + Certbot), spin up databases, and check server health without memorizing Linux commands.
For Designers: Launch staging vs. production sites and custom domains safely in a couple of clicks.
For Developers: Zero public admin panel port exposed on the VPS; provisions isolated non-root containers, Redis, PostgreSQL/MariaDB, and unprivileged Griss workers (127.0.0.1:8765–8772).
1-Click App Marketplace Planned Ecosystem (Post-1.0)

Grabtaculous — 1-Click Self-Hosted Installer

A Softaculous-style one-click app marketplace built right into Gashboard so you can deploy a full stack onto any VPS in seconds.

For Non-Coders / Owners: Install GrabLab + Grex alongside self-hosted analytics, workflow automation, object storage, and webmail without wrestling with Docker files.
For Designers: Spin up complete client starter sites with pre-wired forms, media storage, and SSL ready immediately.
For Developers: Curated, pinned, non-root container templates with repeatable networking, secrets isolation, and clean upgrade paths.

Planned Ecosystem Status & Approval Boundaries

  • Planned Ecosystem Architecture (Post-1.0): GrabLab, Grex & Grex JS, Groxy AI, Gashboard, and Grabtaculous are all Planned (Not Yet Approved for Implementation) and require separate owner approval after GRAB 1.0.
  • What exists today vs. next in line: Single-worker grab serve and SQLite/MariaDB/PostgreSQL database access are live today (GRAB 0.6 & 0.7); multi-worker scaling (--workers) and Redis caching belong to GRAB 0.8 (GRAB-SCALE-SPEC-008.md, currently in review).
