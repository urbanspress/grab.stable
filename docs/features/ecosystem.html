One cohesive stack.
Zero bloat, zero public control-panel login.

Built on the deterministic GRAB language and hardened server engine, the GRAB Ecosystem unites Grisp (our snappy multi-worker server), GrabLab (our savvy CMS), Grex & Grex JS (visual page builder and reactive UI runtime), Groxy AI (local MCP design and CMS agent), Gashboard + Grabtaculous (our discreet desktop VPS manager and 1-click app marketplace), and Groxy Desk (our native Windows WebView2 vibe-coding IDE, local Grisp server manager, and SSH studio).

Roadmap details live in docs/ROADMAP.md and hosting rules live in Deployment Architecture.

Application Server Runtime Builds on 0.6/0.7 · 0.8 & Post-1.0

Grisp — Snappy Multi-Worker Server

The persistent GRAB application server that Nginx or Caddy passes the "rock" to on private loopback ports (127.0.0.1:8765–8772), delivering Swoole/Go-class speed with zero cold starts.

For Non-Coders / Owners: Pages respond instantly instead of booting a heavy script on every visitor click, handling traffic spikes without crashing.
For Designers: Live previews and published sites feel crisp with fast page transitions and clean edge caching.
For Developers: Compiles routes/templates once in RAM (PreparedApp), reuses warm DB/Redis pools, and coordinates zero-downtime reloads via /_ready.
Flagship CMS · Step 2 Active (Spec in Review)

GrabLab — The Savvy CMS

A modern Content Management System built directly on the stable GRAB 1.0 platform (ADR-010) with a Zero-Plugin Core + Exclusive Active Theme architecture—giving teams full publishing power without WordPress plugin/theme bloat.

For Non-Coders / Owners: Manage posts, pages, media, custom content types, roles, and clean URLs (including automatic 301 redirect history when a slug changes) from one organized place.
For Designers: Only one theme is active at a time; custom coded themes or the Grex Visual Theme take 100% exclusive template control without fighting other themes or mystery shortcodes.
For Developers: Strict capability boundaries, deterministic GRAB data contracts, native hooks/filters & query loops, and WordPress-style pretty permalinks (/:slug) out of the box.
Page Builder & Reactive UI · Steps 1 & 3 Grex JS v1.0.0 Complete

Grex & Grex JS — Visual Theme & Engine

A responsive-first visual page builder (Grex, Step 3 Planned) powered by its completed reactive frontend engine (Grex JS v1.0.0, Step 1 Complete)—installing into GrabLab as a first-class Visual Theme that disables any prior theme and takes exclusive template control with zero wrapper-div bloat.

  • Native Responsive-First Elements: Flex/Grid containers, typography, media, forms, nav, tabs/accordions, and dynamic query loops.
  • Global Style & Class Manager: Centralized design tokens and reusable Bricks-style classes with Desktop/Tablet/Mobile breakpoint overrides.
  • Conditional Theme Builder & Dynamic Data Picker: Headers, footers, archives, and 404s bound visually to GrabLab & GRAB data with live preview and rollback.
For Non-Coders, Designers & Developers: Drag-and-drop speed for owners, pixel-accurate classes/breakpoints for designers, and clean semantic HTML + fast Grex JS interactivity for developers.
Autonomous MCP Agent Planned Ecosystem (Post-1.0)

Groxy AI — Autonomous Design, SEO & CMS Expert

An autonomous site designer, SEO auditor, and GrabLab expert agent powered by grab mcp, GRAB-DESIGN-SYSTEM.md, a curated SEO Knowledge & Reasoning Playbook (Semrush, Ahrefs, and Google Search Central best practices), and cost-free local models via Ollama + OpenCode.

For Non-Coders / Owners: Toggle groxy_assist_enabled on any post, product, page, or image: clicking Publish opens a Pre-Publish Grade Review Screen (A+–F / 0–100 across On-Page SEO, Content & WCAG Accessibility, Performance & Clean DOM, and Off-Page / Internal Linking Readiness) with “Make This Live” or 🚀 “Let Groxy Boost This” (side-by-side diff + refreshed grades before “Approve & Make This Live”).
For Designers: Follows spacing, typography, and accessibility guardrails in GRAB-DESIGN-SYSTEM.md using native Grex components instead of messy inline CSS hacks.
For Developers: Pairs deterministic on-page DOM/content auditing with grab mcp CMS & Grex Theme Builder tools (query_entries, create_entry_draft, update_entry_layout, list_media, list_menus).
Desktop VPS Control Panel Planned Ecosystem (Post-1.0)

Gashboard — Discreet Desktop Control Panel

A discreet desktop-based VPS control panel that eliminates public web-panel login attack surfaces by managing your server remotely over encrypted connections.

For Non-Coders / Owners: Point-and-click VPS management—add custom domains with automatic edge SSL (Caddy or Nginx + Certbot), spin up databases, and check server health without memorizing Linux commands.
For Designers: Launch staging vs. production sites and custom domains safely in a couple of clicks.
For Developers: Zero public admin panel port exposed on the VPS; provisions isolated non-root containers, Redis, PostgreSQL/MariaDB, and unprivileged Grisp workers (127.0.0.1:8765–8772).
1-Click App Marketplace Planned Ecosystem (Post-1.0)

Grabtaculous — 1-Click Self-Hosted Installer

A Softaculous-style one-click app marketplace built right into Gashboard so you can deploy a full stack onto any VPS in seconds.

For Non-Coders / Owners: Install GrabLab + Grex alongside self-hosted analytics, workflow automation, object storage, and webmail without wrestling with Docker files.
For Designers: Spin up complete client starter sites with pre-wired forms, media storage, and SSL ready immediately.
For Developers: Curated, pinned, non-root container templates with repeatable networking, secrets isolation, and clean upgrade paths.
Desktop Vibe-Coding IDE · Step 6 Planned Ecosystem (Post-1.0)

Groxy Desk — Native Windows IDE, Local Grisp Manager & SSH Studio

A lightweight native Windows WebView2 + Grex JS v1.0.0 desktop studio (~15–25 MB RAM, zero Electron/Chromium bloat) uniting split-pane vibe-coding, local Nginx-style Grisp (grab.exe) site management, built-in Groxy AI + grab mcp, and SSH database tunneling in one branded .exe installer.

  • Split-Pane Vibe-Coding Shell: Mirrors Google Antigravity's workflow with a Code Editor, Live Split-Screen Grex Theme Builder Canvas, and Groxy AI Agent Sidebar.
  • Local Grisp (grab.exe) Server Manager: 1-click local site creation, start/stop/reload controls, port/local-SSL routing, and isolated SQLite/PostgreSQL/MariaDB environments for local GrabLab CMS + Grex Theme Builder sites.
  • Built-In Groxy AI & grab mcp Runtime: Connects directly to local Ollama models (zero API fees) or user-configured API keys, powered by GRAB-DESIGN-SYSTEM.md, SITE-CONTEXT.md, the 22-rule SEO/A11y/DOM auditor, 8 Design Style Packs, and 🚀 “Let Groxy Boost This”.
  • SSH Tunneling & Deploy Bridge: Local 127.0.0.1 SSH tunnels to remote PostgreSQL/MariaDB databases, Site DNA snapshot sync, and 1-click deployment via grabman.lock to Gashboard + Grabtaculous.
For Non-Coders / Owners: Build and preview local GrabLab + Grex sites with zero terminal setup, let Groxy AI boost pages locally, and deploy in one click.
For Designers: Edit visually side-by-side with live Grex Theme Builder rendering, 8 Design Style Packs, and instant local SSL preview URLs.
For Developers: Full grab mcp + Site DNA workflow, isolated local DBs, and secure 127.0.0.1 SSH tunnels to remote production/staging databases without Electron overhead.
