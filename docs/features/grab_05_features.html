GRAB 0.5: Universal HTTP Client, Lossless JSON & Async Task Groups

GRAB 0.5 connects your programs to the outside world with use http and use json, runs independent API calls in parallel with do together / wait for, and locks down outbound connections with --allow-net and automatic SSRF security.

In one sentence: GRAB 0.5 lets your app talk to live APIs (like payment gateways, shipping calculators, and product catalogs) simultaneously, without losing exact dollar precision or opening security holes.

Why GRAB 0.5 Matters (In Plain English)

How every upgrade in specifications/GRAB-CONNECT-SPEC-005.md helps both the builder and the customer visiting the website.

Builder What It Does for the Coder

  • One-line API calls (use http): Fetch or send data with http.get, http.get_json, http.post, http.put, http.patch, and http.delete—with built-in timeouts and automatic retries.
  • Exact-money JSON (use json): When JSON contains {"price": 19.95}, GRAB decodes 19.95 as an exact base-10 decimal (not a blurry binary float) and lets you read item.price right away.
  • Easy parallel tasks (do together / wait for): Run 3 API calls at the same time in a few readable lines without callbacks, race conditions, or unpredictable output order.
  • Explicit network allowlists (--allow-net): You control exactly which domains a script is allowed to contact.

Visitor What It Does for the Website Visitor

  • Faster page loads: Instead of waiting for inventory, shipping rates, and promotions one after another (e.g. 300ms + 300ms + 300ms = 900ms), do together fetches all three at once in ~300ms.
  • Accurate prices & totals: Visitors never see penny-rounding glitches from external JSON APIs because GRAB preserves exact decimal numbers end to end.
  • Resilient checkout & live data: Bounded timeouts and safe retries mean a brief hiccup on an external API won't freeze the visitor's browser indefinitely.
  • Protection against internal server leaks (SSRF): Even if an external URL redirects somewhere malicious, GRAB automatically blocks private internal networks and cloud metadata addresses.

1. One-Line API Fetch & Lossless JSON (use http + use json)

Exact Decimal Preservation

http.get_json fetches JSON from an approved API and decodes JSON objects directly into GRAB records and exact decimals so you can use item.price and text.from immediately.

use http use json use text # Fetch JSON{"name": "GRAB Starter Kit", "price": 19.95, "in_stock": yes} set item to http.get_json using "https://api.example.com/products/A-17" # item.price is already an exact GRAB decimal (19.95)! set price_badge to "$" joined with (text.from using item.price) show item.name joined with " — " joined with price_badge

Developer benefit: No manual string parsing or floating-point rounding bugs.
Visitor benefit: Always sees up-to-date catalog prices and accurate currency badges.

2. Parallel API Calls with do together / wait for

Deterministic Concurrency

Need product details, live stock count, and shipping window at the same time? Wrap them in do together ... end. GRAB runs them in parallel, isolates their memory so they cannot collide, and always delivers results in exact top-to-bottom order.

checkout_summary.grab — Code Editor
use http try do together set stock to wait for http.get_json using "https://api.example.com/stock" set ship to wait for http.get_json using "https://api.example.com/shipping" end show "Stock: " joined with stock.status joined with " | Delivery: " joined with ship.eta catch err show "Live estimate unavailable (" joined with err.code joined with ")" end
Terminal — Execution Timeline
$ grab run --allow-net api.example.com checkout_summary.grab # Task 1 (stock) and Task 2 (shipping) start at the exact same moment # Both finish in parallel; results commit in top-to-bottom source order: Stock: In Stock | Delivery: 2-Day Express
Developer benefit: If one task fails, GRAB automatically cancels the other in-flight requests and passes the error cleanly to catch err.
Visitor benefit: Pages that combine multiple backend services load in a fraction of the time.

3. Default-Deny Network Security (--allow-net & SSRF Protection)

Capability Security (GRAB-E402)

Just like files in GRAB 0.4, network access is locked by default. You grant access per host with --allow-net, and GRAB automatically blocks sneaky redirects to internal private networks or cloud metadata servers (169.254.169.254).

Blocked Request (No --allow-net Flag)
$ grab run --diagnostics beginner live_catalog.grab live_catalog.grab:6:13: error [GRAB-E402] (network permission denied): outbound network access to "api.example.com" requires --allow-net permission 6 | set item to http.get_json using "https://api.example.com/products/A-17" | ^~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ Hint: Re-run with --allow-net api.example.com to allow requests to this host.
Permitted Request (--allow-net api.example.com)
$ grab run --allow-net api.example.com live_catalog.grab GRAB Starter Kit — $19.95
Developer benefit: Clear GRAB-E402 diagnostic and beginner hint whenever a domain isn't allowlisted yet.
Visitor & server benefit: Scripts can never silently phone home to unknown servers or probe private internal infrastructure.
