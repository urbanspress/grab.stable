Released & Active Milestones (GRAB 0.1 – 0.8)

Each version builds cleanly on the last while keeping existing .grab programs compatible.

GRAB 0.1 Complete

Language Foundation

A clean, deterministic Go-implemented interpreter and CLI for running .grab scripts locally.

  • Variables and output via set, show, and joined with.
  • Portable values: text, Boolean (yes/no), nothing, integers, exact decimals, floats, bytes, lists, maps, and records.
  • Command-line execution via grab run <file.grab> with clear source-located diagnostics.
Spec: GRAB-LANGUAGE-SPEC-001.md Baseline foundation
GRAB 0.2 Complete

Localhost Browser Preview

Separates program logic in .grab files from reusable HTML templates in .grab.html files.

  • Simple {identifier} placeholders and literal {{ / }} braces inside HTML templates.
  • Context-aware HTML escaping to help protect visitors against XSS and broken markup.
  • Loopback-only dev server via grab serve on 127.0.0.1:8080.
Spec: GRAB-LOCALHOST-SPEC-002.md Live preview enabled
GRAB 0.3 Complete

Control Flow, Functions & Richer Language

Turns GRAB into a general-purpose programming language with conditions, bounded loops, math, and reusable functions.

  • Branching & loops: if / otherwise if / otherwise, repeat, for each, and while (with 1,000,000-step safety guard).
  • Functions (make / using / give back / call) with isolated call frames and 256-frame limit.
  • Exact decimal/integer arithmetic, comparisons, Boolean logic, and .field / at / has lookups.
Spec: GRAB-LANGUAGE-SPEC-003.md Benchmark harness added
GRAB 0.4 Complete

Core Standard Library, Error Model & Permissions

Brings built-in helpers (text, math, collections, dates, files), crash recovery, capability security, and developer CLI checks.

  • use text (including text.from for $19.95 badges), math, collections, dates, and files.
  • try / catch / raise error handling with stable GRAB-E... codes and beginner / developer / production modes.
  • Default-deny filesystem safety (--allow-read / --allow-write) plus grab check and grab format.
Spec: GRAB-STDLIB-SPEC-004.md Open GRAB 0.4 Visual Guide →
GRAB 0.5 Complete

HTTP Client, Lossless JSON & Async Task Groups

Connects GRAB programs to external APIs safely with use http, exact-decimal use json, --allow-net permissions, and parallel do together / wait for blocks.

  • Universal HTTP client (GET, POST, PUT, PATCH, DELETE, get_json) with custom headers, timeouts, and bounded retries.
  • Lossless JSON encoding/decoding preserving exact integer and decimal numbers and unified .field / at lookup.
  • Default-deny --allow-net host allowlists, SSRF protection, and deterministic do together / wait for concurrency.
Spec: GRAB-CONNECT-SPEC-005.md Open GRAB 0.5 Visual Guide →
GRAB 0.6 Complete

Persistent Multi-Route App Server (GRAB Server)

Turns GRAB into an always-on web application server with natural route handlers, use server responses, load-once PreparedApp startup, and production safety behind Nginx.

  • Natural route "GET" "/products/{id}" using req routing and server.html / server.json / server.redirect helpers.
  • Immutable load-once app startup with fresh per-request isolation (zero cross-visitor data leaks) and bounded concurrency queues.
  • Safe loopback default, --allow-public & --trusted-proxy Nginx integration, opt-in --static file serving, /_health & /_ready probes, and atomic reload.
Approved Spec: GRAB-SERVER-SPEC-006.md Open GRAB 0.6 Guide →
GRAB 0.7 Complete

Database Access (GRAB Data)

Adds persistent, default-deny database access via use data across SQLite, MariaDB, and PostgreSQL with prepared queries, exact types, explicit transactions, and versioned migrations.

  • Fixed literal SQL and explicit type contracts (data.open, data.prepare, one, query, execute) preserving exact decimals and nothing for NULL.
  • Default-deny --db-config manifest and --allow-db grants (read, read-write, maintenance-only migrate), confined rollback-journal SQLite on Windows/Linux amd64, and verified TLS for remote servers.
  • Scoped transactions (begin / commit / rollback), grab migrate, persistent-server pool cleanup, and the runnable SQLite catalog in examples/DATA.md.
Approved Spec: GRAB-DATA-SPEC-007.md Open GRAB 0.7 Guide →
GRAB 0.8 Implemented (100% Tests Pass)

Integrations, Client Adapters & Scaling

Brings Redis caching/rate limiting, typed JSON API contracts with deterministic TypeScript/React generation, verified connectors, durable 3-engine event queues, WebSocket channels, multi-worker process supervision, and OTLP/OpenMetrics telemetry.

  • Memory and standalone Redis caches with atomic fixed-window rate limits via use cache.
  • Typed API contracts (use api) and deterministic TypeScript / React client generation via grab generate client.
  • Signed webhooks and durable transactional inbox/outbox event queues on SQLite, MariaDB, and PostgreSQL (use events).
  • Authorized WebSocket channels (use sockets), supervised multi-worker loopback processes (--workers), and opt-in OTLP/OpenMetrics telemetry.
Approved Spec: GRAB-SCALE-SPEC-008.md Open GRAB 0.8 Guide →
